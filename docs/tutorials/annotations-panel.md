# Annotations in the Datapoints Panel

## Why annotate from the panel

The Datapoints panel is built for investigation:

- You’re already looking at the exact time range.
- You can add context next to multiple correlated targets.
- You can confirm the annotation aligns with the data before saving it.

## Workflow: mark an anomaly

### Step 1 — Find the moment of change

Use the timeline slider to locate the first deviation.

See: [/tutorials/range-explorer](/tutorials/range-explorer)

### Step 2 — Create the annotation

Create an annotation at the timestamp that best represents the event:

- first deviation (start)
- peak or minimum (impact)
- recovery (end)

### Step 3 — Add details that help future-you

Include:

- what you observed
- what you suspect caused it
- what you changed (if you took action)

Example:

> `Basement humidity spike: dehumidifier full / stopped`

### Step 4 — Validate with comparisons

Use a comparison window to check if the pattern is common or rare.

See: [/tutorials/comparisons](/tutorials/comparisons)
