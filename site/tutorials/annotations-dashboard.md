# Manual Annotations (Dashboard)

## When to use dashboard annotations

Use the dashboard card when you want quick, low-friction tagging:

- “Something weird happened” and you want to mark it instantly
- A recurring event you want to track (laundry cycle start, sauna heating, EV charging)
- A manual “I did this” marker to compare against data later

## Workflow: add an annotation in 10 seconds

1. Open your dashboard view containing the datapoints card.
2. Press **Add annotation** (or equivalent UI).
3. Pick a time (usually “now”) and enter a short label.
4. Save.

## Best practice: write labels you can search later

Good:

- `HVAC: filter changed`
- `Dishwasher: started`
- `Shower: started`
- `Basement: dehumidifier on`

Avoid:

- `weird`
- `test`
- `hmm`

## Next step: verify in the panel

After saving, jump to the Datapoints panel and confirm the annotation lines up with the signal range you care about.
