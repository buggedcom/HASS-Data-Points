# Features

## Range exploration (timeline slider)

The timeline slider is the fastest way to move across time:

- Jump from “hours” to “days” without losing context.
- Zoom into a spike, dip, or step-change in seconds.
- Keep a stable selection while you add/remove targets.

## Target rows drive the chart

Targets describe what the chart should show (entities, statistics, transformations, and display settings).

- Add multiple targets to compare signals.
- Use consistent settings across different ranges.
- Build reusable “analysis layouts” for the sensors you care about.

## Comparison windows

Validate what you’re seeing by comparing different time windows:

- Same weekday last week vs today
- Yesterday vs today
- “Known good” vs “suspected anomaly”

See: [/tutorials/comparisons](/tutorials/comparisons)

## Annotations (datapoints)

Create annotations so charts have context:

- Manual from a dashboard card (quick ad-hoc tagging)
- From the Datapoints panel (deep investigation)
- From automations (capture events at the moment they happen)

See the full annotation guide:

- [/tutorials/annotations-dashboard](/tutorials/annotations-dashboard)
- [/tutorials/annotations-panel](/tutorials/annotations-panel)
- [/tutorials/annotations-automations](/tutorials/annotations-automations)

## Anomaly workflows

hass_datapoints is designed to make anomaly investigation repeatable:

- Find the time of change quickly (slider + zoom)
- Compare “now vs normal” (comparison windows)
- Record context as annotations
- Track recurring patterns over weeks

Start here: [/tutorials/anomalies](/tutorials/anomalies)
