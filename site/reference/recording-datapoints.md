# Recording datapoints (annotations)

Annotations can be recorded in three ways:

1. Manual from a dashboard card
2. Manual from the Datapoints panel
3. Automatically from Home Assistant automations

## What to record

Record datapoints that help interpret “why the data looks like that” later:

- maintenance (filter changes, device replacements)
- human routines (shower, cooking, sauna, EV charging)
- environment changes (windows opened, doors left open)
- system actions (automation change, firmware update)
