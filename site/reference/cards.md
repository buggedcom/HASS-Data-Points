# Cards

This page describes the main user-facing cards at a high level and how they fit into typical workflows.

## Dashboard annotation card

Use this when you want quick manual annotations directly from a dashboard.

Best for:

- “bookmark now”
- manually tagging events
- capturing human context

See: [/tutorials/annotations-dashboard](/tutorials/annotations-dashboard)

## History / sensor surfaces

Use these when you want to explore a single entity or a small set of entities with a consistent chart configuration.

Best for:

- daily monitoring
- confirming a hypothesis quickly
- iterating on target settings before moving to a deeper investigation

## Datapoints panel

Use this when you want full investigation tooling (range explorer + comparisons + multiple targets + annotation browsing).

Best for:

- troubleshooting
- anomaly investigation
- building repeatable “analysis layouts”

See: [/tutorials/annotations-panel](/tutorials/annotations-panel)
